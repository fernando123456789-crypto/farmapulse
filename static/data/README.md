# Área de reparto

`area_reparto.geojson` contiene los distritos 150130 (San Borja), 150134 (San Luis) y 150115 (La Victoria), extraídos sin simplificación adicional de [juaneladio/peru-geojson](https://github.com/juaneladio/peru-geojson/blob/master/peru_distrital_simple.geojson), consultado el 16 de octubre de 2026. El repositorio declara como fuente INEI-2007, distribuida por MINAM/GEOIDEP, y licencia MPL-2.0; se incluye su licencia original.

Estos polígonos definen la cobertura operativa configurada de FarmaPulse. No constituyen un certificado de límites legales ni de existencia de números de puerta. Se deben actualizar cuando cambie la cobertura comercial o la cartografía utilizada.
